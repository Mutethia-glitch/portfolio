01 / THINK CLEARLY

Know what matters.

Start with real user flows and the constraints underneath them, not features for the sake of features.

02 / BUILD DEEPLY

Secure the foundation.

03 / SHIP HONESTLY

Build, test, document, iterate. No invented metrics or features that only work in a mockup.
